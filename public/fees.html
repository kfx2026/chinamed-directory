病例提交

病例提交与脱敏规范

为给您做准确评估，我们接受通过邮箱发送病例资料；发送前请务必完成脱敏——我们只看医学信息，不看您的身份。

① 发送前「必须脱敏」的字段

字段处理方式
姓名用化名 / 编号替代（如「患者 A」）
性别如非病情判断必需，请脱敏；若保留请明确标注「与病情相关」
年龄改为年龄段（如「50 余岁」）或脱敏
住宅地址完全删除
身份证 / 护照号完全删除
手机号 / 固定电话完全删除
电子邮箱文件内若含其他邮箱请删除（您用来发送的邮箱仅作联系用途）
工作单位 / 学校完全删除
人脸照片 / 含面部的影像遮挡面部
社保号 / 医保卡号完全删除

② 可保留的医学信息（去标识后足以评估）

  • 诊断结论、病理报告
  • 检验 / 影像结果（DICOM、CT / MRI / 超声报告）
  • 用药清单、过敏史
  • 手术 / 治疗史、病程摘要
  • 既往出院小结（请先脱敏上述身份字段）

③ 脱敏操作指引（三步走）

1

替换

姓名 → 化名，年龄 → 年龄段。

2

涂黑 / 删除

身份证、住址、电话、邮箱、单位、人脸等，用黑块遮挡或直接删去。

3

自查

发送前再扫一遍文件，确认没有任何可直接定位到您本人的信息。

🔒我们如何对待您发来的资料
